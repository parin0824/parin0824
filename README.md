## Featured Projects

### High Speed Neural Network Accelerator with Ring Bus
- Built a **1 GHz neural network engine** in SystemVerilog performing **42 parallel E5M6 floating-point MAC operations**
- Used pipelined fixed-point **24.24 accumulation** with **48-bit precision output**
- Integrated the design into a **1008-bit token-based ring bus** with a central HUB interconnect
- Verified correctness and timing through **simulation and synthesis**

### Ethernet MAC TX Verification with ML-Driven Test Generation
- Developed a **UVM testbench** in SystemVerilog for the **Xilinx Ethernet MAC transmit path**
- Achieved **85%+ functional coverage** with **25+ test cases**
- Used **Python and scikit-learn** to guide stimulus generation
- Reduced the number of tests needed to reach target coverage by **18%** versus random testing

### UVM Based Verification of AXI4 Lite Protocol
- Implemented an **AXI4 Lite slave** with FSM-based read/write control and memory-mapped storage
- Verified the design using a **UVM environment** with constrained-random sequences, driver, monitor, and scoreboard
- Validated **20+ directed and random transactions** with **zero protocol violations**

### RTL Design and Verification of Cache Memory Controller
- Collaborated in a **team of 3** to design a **1 KB direct-mapped cache**
- Implemented **write-back** and **write-allocate** behavior using a **4-state FSM controller**
- Verified operation through simulation and FPGA implementation on **NEXYS 4 using Vivado**
- Achieved **1-cycle hit latency**, clean miss allocation, and dirty miss write-back

### Design and Verification of Asynchronous FIFO
- Designed a **128-bit asynchronous FIFO** in Verilog using **dual-port RAM**
- Implemented **Gray-coded pointers** and **CDC-safe synchronization**
- Added full/empty detection and threshold alerts
- Verified asynchronous behavior and data integrity in **AMD Vivado**

### Machine Learning Based Network Packet Classifier
- Trained a **decision tree classifier** on real-world traffic header data using the **Cognichip AI platform**
- Converted the trained model into **synthesizable RTL**
- Achieved **~98% test accuracy**
- Built a **low-power pipelined SystemVerilog module** with clock gating and gray-coded outputs
- Secured **3rd place in a university hackathon**

### Design and Verification of RISC-V Processor
- Designed a **single-cycle RV32I processor** with **16 registers** and **32-bit opcodes**
- Built a **32-bit ALU** with custom operations
- Synthesized at **26 MHz** with **11,000+ gate count**
- Verified fetch, decode, execute, and control units using **SystemVerilog testbenches** and **RISC assembly-based tests**

### FPGA Computer Vision Pipeline Development
- Developed an FPGA image-processing pipeline for **wildfire detection**
- Implemented modules for **frame synchronization, denoising, motion detection, and edge detection**
- Integrated an **INT8 CNN classifier** with simulated thermal and RGB inputs

### FPGA-Based Real Time Video Stabilization System
- Designed custom **Motion Estimator** and **Affine Warper** IPs on a **Zynq-7000 (Zybo Z7-7010)** FPGA
- Built a low-latency real-time video stabilization pipeline using **AXI-Stream**
- Integrated **PCAM camera input, VDMA buffering, AXI-Lite control, and HDMI output**
- Enabled **real-time 720p stabilized video processing**

### ALU Verification Using UVM
- Built a reusable **UVM verification environment** for multiple ALU DUTs
- Used layered components including **agent, sequencer, driver, monitor, and scoreboard**
- Implemented constrained-random and virtual sequences for arithmetic, logic, shift, and flag checks
- Achieved high functional coverage across parallel DUT instances
